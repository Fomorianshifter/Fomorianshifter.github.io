Loki

Embedded companion for a Linux single-board computer. Hardware layer for GPIO, SPI, I2C, UART, and PWM. Drivers for a TFT, SD, flash, EEPROM, and Flipper Zero UART. Local config UI on the USB network.

github.com/Fomorianshifter/Loki

  • Language: C, with Python around the local UI.
  • Topics: embedded systems, Orange Pi, Raspberry Pi, TFT, Flipper Zero.
  • MIT license. Strongest public hardware project on the account.

Loki

Public embedded project for a Linux single-board computer. Dragon-themed companion with hardware drivers and a local configuration UI.

github.com/Fomorianshifter/Loki · MIT · C and Python

  • HAL modules for GPIO, SPI, I2C, UART, and PWM.
  • Drivers for TFT, SD card, flash, and EEPROM.
  • Flipper Zero UART command path.
  • Life-cycle state machine: egg, hatchling, young, adult, with hunger, mood, and animation states.
  • Local web config UI intended for the USB network address 10.0.0.2.

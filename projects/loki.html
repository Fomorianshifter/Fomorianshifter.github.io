Loki

Embedded C companion for a Linux single-board computer. The interesting part for a controls reader is the hardware split, not the dragon theme.

Hardware layers

HAL modules for GPIO, SPI, I2C, UART, and PWM. Separate drivers for a TFT display, SD card, flash, EEPROM, and Flipper Zero UART.

Runtime

Startup and shutdown path, leveled logging, tracked allocation helpers, and retry logic for flaky bus calls. Local config UI on the board network.

Status

Public, MIT licensed. The README still has an unresolved merge-conflict marker. Treat it as a working learning project, not a shipped product.

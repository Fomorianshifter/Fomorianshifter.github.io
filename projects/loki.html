Loki

Embedded dragon companion for Linux single-board computers. C core, hardware drivers, TFT UI, and Flipper Zero over UART.

GitHub source Life-cycle demo

What it shows

  • Hardware abstraction for display, storage, and serial
  • Local configuration UI on a small TFT
  • UART integration with Flipper Zero
  • State-machine behavior (idle / hunt / rest) — see the browser sketch

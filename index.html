Basic projects made for this portfolio

These run in the browser. They are small on purpose: a foundry fault log, a motor-starter check, and a voltage-drop calculator an electrician would actually open.

Shift fault log

Log a call, mark it cleared, and keep the board for the next shift. Stored in this browser only.

Starter check

Three-wire motor start/stop. Seal-in only holds if stop is closed and the overload is reset.

Voltage drop

One-way length, load amps, and conductor size. Uses approximate copper resistance, not a code table.

Loki status

Small model of the Loki life-cycle: feed, interact, and watch stage and mood change.

About

I’m Nicholas Lane — Beau on GitHub as @Fomorianshifter. I ship web interfaces and study the hardware underneath them: C on single-board computers, Python for device UIs, and the electrical path that keeps industrial work safe.

The through-line is systems. How a function sits on a plane. How a HAL talks to a display. How a circuit is labeled so the next person can trust it. I learn in public, keep the repos honest, and treat curriculum work as foundation rather than a finished product.
